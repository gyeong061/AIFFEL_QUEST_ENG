# 07. Blocked Items

아래 항목은 임의로 결정하지 않고 BLOCKED 상태로 남긴다. 웹뷰에는 확정 전까지 플레이스홀더/Mock으로만 표시한다.

~~1. PAR-Q 7문항 원문~~ → **[RESOLVED]** 사용자가 전신체상태설문지(PAR-Q) 확정 원문 7문항을 직접 제공하여 반영 완료(CONFIRMED). 코드 내 `PARQ_QUESTIONS` 배열 교체, 문항별 차등 판정 없이 공통 판정(1개 이상 '예' → 자가측정 차단)만 유지.

2. **백분위 계산 공식 / 실제 규준 데이터** — §11 구간 폭 초기값만 CONFIRMED이며, 실제 규준 테이블·정규화 방식은 미확정. 화면은 `MOCK DATA` 예시값만 사용.
3. **입력 정상범위 수치(§30)** — 검증 로직 구조는 구현하되, 항목별 정상 범위 값 자체는 임의 결정하지 않음. UI에는 `범위 미확정(BLOCKED)`로 표기, 현재는 빈값/음수만 차단.
4. **운동-요인 매핑 데이터(§35)** — 실제 처방 콘텐츠 연결 전까지 예시 문구만 `MOCK DATA`로 표시.
5. **Backend API Request/Response 스키마** — §38 원칙에 따라 placeholder만 존재.
6. **norm_version_used 실제 값** — 버전 문자열 미확정.
7. **국민체력100 실제 인증 로그인 연동** — 이번 MVP는 Mock 로그인만 구현.

STEP 14 기준, 위 7개 항목은 결정권자 확인 후 반영 예정.
