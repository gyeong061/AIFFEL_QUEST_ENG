# DLthon2 — 그림체(Style) Visual RAG: 4컷 만화 생성

한 줄 이야기와 원하는 그림체를 넣으면 그 그림체를 유지한 4컷 만화를 만드는 팀 프로젝트입니다.
그림체를 말로 설명하는 대신, 코퍼스에서 그 그림체의 실제 이미지를 **검색**해 생성 모델에 함께 넣습니다.
찾아오는 대상이 문서가 아니라 그림일 뿐, 구조는 RAG와 같습니다.

- 기간: 2026-07-30 ~ 08-11 (AIFFEL DLthon2)
- 팀: 김민욱(팀장) · 강경수 · 김수경 · 조희연 · 채진현
- 팀장 기록 저장소: https://github.com/MinWookGim/AIFFEL_Quest_eng/tree/main/05_LLM/DLthon_RAG
  (기획, 채점기 kit, 생성 파이프라인, 최종 발표자료)

## 핵심 결과 (daypack_v2: 2,522장 · 20스타일 · Top 5)

| 방법 | Style-Macro mAP@5 | 차원 |
|---|---:|---:|
| CLIP 기준선 | 0.3536 | 512 |
| 전체 Gram (VGG19) | **0.4033** | 174,560 |
| 저층 Gram | 0.3234 | 10,336 |
| CLIP + 저층 Gram (0.50) | 0.3861 | 10,848 |
| CLIP + 저층 Gram + HSV | 0.3882 | 10,896 |

- **CLIP과 Gram은 서로 보완한다.** 0.50 결합이 CLIP보다 +0.0325 높았고, 대응 부트스트랩 95% 구간(+0.0251 ~ +0.0397)이 0을 넘었습니다.
- **저층 Gram만으로는 부족하다.** 차원은 약 1/17로 줄었지만 점수가 0.4033에서 0.3234로 떨어졌습니다.
- **HSV는 paint를 보완하지 못했다.** 전체 점수 차이는 95% 구간이 0을 포함해 확정할 수 없었고, paint 내부 AP@5는 오히려 내려갔습니다.
- **도메인마다 유리한 표현이 다르다.** paint는 CLIP이, ink·vector는 Gram이 상대적으로 강했습니다. 발표 10장 "섞는 비율 하나로는 안 된다"와 같은 방향의 관찰입니다.

> 위 숫자는 평가 프로토콜 v3 보완 **이전** 결과입니다. 상세 조건은 `DLthon_RAG_프로젝트_진행상황.md`를 보세요.

## 실행 방법

1. Google Drive에 `DLthon_RAG` 폴더를 만들고 필요한 ZIP을 넣습니다.
   - 공통: `daypack_v2.zip` (팀 내부 공유 데이터)
   - 검색 표현 실험: 팀 채점기 kit ZIP
   - 스타일 전용 검색: `style_search_final_code.zip`
2. Colab에서 T4 GPU를 켜고 노트북을 위에서부터 실행합니다.
3. LLM 재작성 모드(`llm`, `canonical_first`)를 쓰려면 Colab Secrets에 `OPENAI_API_KEY`를 등록합니다. `canonical_only`는 키 없이 실행됩니다.
