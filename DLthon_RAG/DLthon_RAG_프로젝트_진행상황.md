# DLthon 그림체 RAG 프로젝트 진행 상황

> 최종 업데이트: 2026-07-30  
> 현재 단계: **평가 프로토콜 v3 보완 완료 → 동일 판 전체 재실행 대기**

## 1. 프로젝트 목표

사용자가 원하는 그림체와 유사한 레퍼런스 이미지를 검색하고, 검색 결과를 이미지 생성
모델에 전달하여 그림체가 반영된 결과물을 만드는 RAG 시스템을 구축한다.

현재는 전체 과정 중 **레퍼런스 이미지 검색 성능을 개선하고 평가하는 단계**다.

## 2. 고정 조건

- 데이터: `daypack_v2.zip`
- 이미지 수: 2,522장
- 스타일 수: 20개
- 도메인: ink, paint, vector
- 검색 결과: Top 5
- 자기 자신과 같은 원본 그룹은 검색 후보에서 제외
- 데이터 추가·교체 없이 검색 표현과 결합 방법만 변경

## 4. 완료된 평가 항목

### 대표 지표

- **Style-Macro mAP@5**
  - 질의별 검색 순서를 AP@5로 평가
  - 스타일별 평균을 먼저 계산
  - 20개 스타일에 동일한 가중치를 부여

- 임베딩 차원

## 7. 최종 검색 방법 선정 기준

1. Style-Macro mAP@5가 기준선보다 높은가?
2. 대응 비교의 95% 구간이 0보다 큰가?
3. paint를 개선하면서 ink와 vector가 크게 하락하지 않는가?
4. 점수 상승에 비해 인덱스 크기와 실행 시간이 감당 가능한가?
5. NICE/Bad 사례에서 실제 검색 결과가 납득 가능한가?

점수 차이가 확실하지 않으면 더 작은 차원과 더 짧은 검색 시간을 가진 방법을 선택한다.

## 8. 현재 확인할 가설

### 가설 1 — 저층 Gram으로 충분한가?

전체 Gram의 고차원 특징을 제거해도 질감 검색 성능을 유지할 수 있는지 확인한다.

**결과:** 지지되지 않음. 차원은 약 16.9배 줄었지만 Style-Macro mAP@5가
0.4033에서 0.3234로 하락했다.

### 가설 2 — CLIP과 Gram은 상호 보완적인가?

CLIP의 의미·색·구도 정보와 Gram의 질감 정보를 결합했을 때 전체 대표 점수가
상승하는지 확인한다.

**결과:** 지지됨. 0.50 결합은 CLIP보다 +0.0325 높았고 대응 95% 구간 전체가
0보다 컸다.

### 가설 3 — HSV가 paint를 보완하는가?

색 분포를 소량 추가했을 때 paint 내부 성능이 개선되는지 확인한다. paint만 오르고
전체 대표 점수가 떨어진다면 최종 방법으로 바로 채택하지 않는다.

**결과:** 지지되지 않음. 전체 점수는 +0.0021 올랐으나 확정적이지 않았고 paint
내부 AP@5는 오히려 0.0231 하락했다.

- [ ] 동일 장면·시드·설정으로 생성 방법 비교

### 생성 결과용 평가 지표

| 평가 목적 | 후보 지표 |
|---|---|
| 검색된 그림체 반영 | Style Margin + 인간 평가 |
| 장면 내용 반영 | CLIPScore + 인간 평가 |
| 4컷 그림체 유지 | Panel Style Consistency |
